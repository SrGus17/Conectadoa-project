# Conectadoa

Sistema de gestão de doações para a ONG Conectadoa.

Projeto Integrador Extensionista · ADS.

## Requisitos

- Git
- Vite+ (comando vp): https://viteplus.dev

## Como rodar

1. Clone o repositório e entre na pasta:

   `git clone https://github.com/SrGus17/Conectadoa-project.git`

2. Instale as dependências:

   `vp install`

3. Configure o arquivo `server/.env` com as credenciais do banco de dados.

4. Terminal 1, inicie a API:

   `npm.cmd run api`

5. Terminal 2, inicie o frontend:

   `npm.cmd run dev`

6. Abra http://localhost:5174
